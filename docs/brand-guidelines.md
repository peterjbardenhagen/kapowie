# Kapowie Brand Guidelines

## Brand Mark

- Primary logo: stylized `K` with a lightning-bolt cut through the center
- Supporting motif: circular arc ring around the mark
- Wordmark: heavy geometric sans-serif with rounded counters
- Tone: energetic, technical, fast, and self-hosted

## Color System

The palette below is sampled from the supplied brand image and tightened for consistent use.

### Core Colors

- `Kapowie Navy` - `#070B2A`
- `Midnight Blue` - `#10183E`
- `Electric Purple` - `#7A2CFF`
- `Violet` - `#A13DFF`
- `Azure Blue` - `#3C7BFF`
- `Cyan Blue` - `#45B0FF`

### Accent Colors

- `Neon Pink` - `#E83BFF`
- `Signal Green` - `#2EE66B`
- `Alert Red` - `#FF4A4A`

### Neutral Colors

- `Off White` - `#F6F7FB`
- `Slate` - `#A0A8C0`
- `Charcoal` - `#1A1F33`

## Recommended Gradient

- Hero gradient: `linear-gradient(135deg, #7A2CFF 0%, #45B0FF 100%)`
- Secondary glow: `linear-gradient(135deg, #E83BFF 0%, #7A2CFF 60%, #45B0FF 100%)`

## Usage Guidance

- Use `Kapowie Navy` or `Midnight Blue` as the default background.
- Use the purple-blue gradient for hero highlights, active states, and key brand surfaces.
- Use neon accents sparingly for live indicators, recording states, and calls to action.
- Avoid generic purple-only UI treatment; keep a strong contrast between the dark base and the electric accents.
- Prefer crisp geometric typography and sharp spacing over soft rounded marketing layouts.

## UI Direction

- Backgrounds should feel deep and cinematic, not flat white.
- Motion should be purposeful: one or two layered glows, not constant micro-animation.
- Surfaces should use subtle borders and soft glow shadows instead of heavy filled panels.
- The logo should be treated as a badge or launch mark, with the wordmark used separately in dense UI areas.

## Enhancement Notes

- The supplied image is strong enough to support a polished dark-mode brand system.
- If you want a more premium product feel, keep the same palette but reduce saturation slightly in app chrome and reserve the brightest blue/purple only for action states.
- A cleaner production version of the logo should be exported as SVG for the wordmark and app icon, with the bolt and ring separated into reusable layers.
