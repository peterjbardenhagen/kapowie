Products

Two ways to use Kapowie — pick the one that fits your setup.

Chrome Extension

MV3 extension. Auto-detects HLS/DASH streams, records, and re-streams via a local HLS server.

cd extension
npm install
npm run build

Windows Desktop App

Tauri native app. No browser memory limits, RTSP re-streaming, and scheduling.

cd desktop
npm install
npm run tauri dev

How it works

  1. 01

    Detect

    Content script spots a live <video> element or an HLS/DASH manifest request.

  2. 02

    Capture

    Segments download concurrently, decrypt if needed, and mux to MP4 — all locally.

  3. 03

    Re-stream

    A local HLS server (and RTSP on desktop) serves the stream to any device on your network.
