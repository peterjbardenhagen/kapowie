Privacy Policy

Last updated: June 30, 2026

Short version: Restreamer.ai does not collect, store, or transmit any of your personal data. Everything the extension does happens locally on your device. No account required. No analytics. No third-party data sharing.

1. Who we are

Restreamer.ai is an open-source project maintained by Peter Bardenhagen (peter@bardenhagen.xyz). The Restreamer.ai Chrome extension, desktop app, and website are all freely available under the MIT License at github.com/peterjbardenhagen/Restreamer.ai.

2. What data the extension accesses

The Restreamer.ai Chrome extension requests the following browser permissions to function:

  • webRequest / declarativeNetRequest — detects HLS/DASH stream URLs from network traffic on pages you visit. This data is used only to identify the stream URL; it is never stored, logged, or sent anywhere.
  • activeTab / scripting — injects a small content script on the current tab to observe the video element and discover the stream source. Used only for stream detection; the extension reads no page content beyond the stream URL.
  • tabs — reads the current tab URL so the content script knows which page it is running on. Used solely for detection logic.
  • storage — saves your extension settings (selected quality, output format preferences) locally using chrome.storage.local. Nothing is synced to Google's servers or any external service.
  • downloads — writes the recorded video file to your Downloads folder (or a folder you choose) after muxing is complete. The extension does not upload files anywhere.
  • offscreen — opens a hidden document to run FFmpeg (compiled to WebAssembly) for muxing stream segments into an MP4 file. All processing is local.
  • host permissions (all URLs) — required to fetch the stream segment files (HLS .ts / DASH .m4s files) from whichever server the stream originates on, and to inject CORS headers so the browser can download them. The extension does not read page content through these permissions.

3. Data we do NOT collect

Restreamer.ai never collects, stores, or transmits:

  • Your browsing history or visited URLs
  • The content of pages you visit
  • Your personal identity or email address
  • Usage analytics or crash reports
  • The video content you record
  • Any form of telemetry

4. Local processing only

All stream downloading, segment decryption (AES-128), and video muxing (FFmpeg.wasm) occurs entirely within your browser on your local machine. Recorded files are saved directly to your local disk via the chrome.downloads API. Restreamer.ai has no backend server and makes no outbound connections on your behalf (other than fetching the stream segments themselves from the streaming provider's servers, which is the same request your browser would make to play the video).

5. Third-party services

The extension does not load any third-party analytics, advertising, or tracking scripts. The FFmpeg WebAssembly core is bundled directly inside the extension package — it is not fetched from a CDN at runtime.

The Restreamer.ai marketing website (restreamer.ai) is hosted on Vercel and loads Google Fonts. Vercel's and Google's own privacy policies apply to those interactions. The website has no login, no forms, and does not set cookies.

6. Children's privacy

Restreamer.ai is not directed at children under 13. We do not knowingly collect any information from children.

7. Changes to this policy

If we make material changes to this policy, we will update the "Last updated" date above and commit the change to the public GitHub repository, where you can view the full history.
